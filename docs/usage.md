# 使い方

[README](../README.md) / [セットアップ・設定](../XANGI_SETUP.md) / [設計](design.md)

## 画面操作

1. xangiの拡張一覧から「xangi-remote-desktop」を開きます。
2. 自動認証を使う場合は初回にブラウザを登録します。コードの確認方法は画面内にあります。
3. 「接続する」で画面を表示します。手入力モードではVNCの認証情報を入力します。
4. 「操作を開始」を押し、画面内をクリックするとマウス・キーボードで操作できます。
5. 「操作を停止」で入力を止め、「切断」で終了します。「xangiホーム」で戻れます。

「画面に合わせる」は表示倍率だけを変え、PCの解像度は変えません。対応ブラウザでは全画面表示を使えます。同時接続は1ブラウザまでで、切断後の再接続は手動です。VNCに直接接続する別クライアントはこの制限に含みません。

登録期限の変更・コードの再表示・全登録失効は[セットアップ](../XANGI_SETUP.md#登録コードの確認)を参照してください。

## 対応状況

| 対象 | 対応・検証状況 |
| --- | --- |
| Linux X11 | Chromiumで画面表示・マウス／キー入力を確認 |
| Linux Wayland | 環境別の実機検証が必要。RDPのみのサーバーには非対応 |
| macOS | POSIXランチャーあり。標準画面共有・Apple固有認証は実機未検証 |
| Windows | ネイティブ起動ランチャー・実機検証は未対応。WSLからWindows画面への接続も未保証 |
| ブラウザ | Chromiumで検証。Safari・Firefoxは未検証 |

自動認証はRFB 3.3/3.7/3.8の標準VNCパスワード認証のみ対応します。手入力でも証明書の手動承認やusername/password以外の入力が必要な方式は非対応です。日本語IME・特殊キー・複数画面・OSロック・UAC・ログイン画面は未検証です。

## 困ったとき

- **接続できない**：VNCの待ち受け先・ポート・認証情報、別タブの接続有無を確認します。`doctor`はVNCへの接続成功までは確認しません。
- **登録を保存できない**：Cookieの許可と、設定に合ったHTTPS等の接続先を確認します。
- **入力できない**：「操作を開始」が有効か、画面内にフォーカスがあるか確認します。
- **手入力の認証が動かない**：方式によってWeb Cryptoが必要です。HTTPSまたはlocalhostを使用します。

## 制限

「入力停止」は誤操作防止で、閲覧専用の権限ではありません。登録済みブラウザを持つ人はPCを操作できます。xangiへのアクセスを本人・許可した利用者に制限してください。

音声・ファイル転送・クリップボードUI・解像度変更・OSの自動設定・利用者ごとの操作権限・AIへの操作権の引き渡しは含みません。
