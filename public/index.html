このブラウザを登録

初回だけ管理者から受け取った登録コードを入力してください。既定では30日間「接続する」だけで使えます。共有端末では登録しないでください。

登録コードの確認方法

自分で導入した方：PCのターミナルで、この拡張のディレクトリへ移動して実行します。

npm run registration -- show

初回セットアップ中は npm run setup で設定を確認し、コードを表示できます。

管理者が導入した場合：管理者に登録コードを依頼してください。VNCパスワードとは別のコードです。

このコードを持つ人はPCを操作できます。公開のチャットや共有端末には残さないでください。

Cookieを削除した場合やブラウザ側で保存期限が切れた場合は、再登録が必要です。

接続後は画面を見るだけです。「操作を開始」でマウスとキーボードを使えます。
